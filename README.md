# Body OS — v1 (веб-приложение)

Персональный коуч по телу по ТЗ «Body OS — ТЗ v1». Вместо iOS-приложения сделано веб-приложение (PWA):
ставится на iPhone через «На экран Домой», работает офлайн, данные хранятся только на устройстве.

## Запуск на компьютере

Двойной клик по `start.bat` или:

```
python server.py 8020
```

Открыть http://127.0.0.1:8020. Тесты ядра: http://127.0.0.1:8020/tests/

## На iPhone

Для установки и офлайна нужен HTTPS. Подходит любой статический хостинг (GitHub Pages, Cloudflare Pages, Netlify):
папку выкладывать целиком, сборка не нужна. В Safari: «Поделиться → На экран Домой».

## LLM

«Ещё → LLM»: ключ Claude API, адрес (можно свой прокси), модели. Разбор еды — `claude-haiku-5-5`,
сводки, ответы «почему» и анализы — `claude-sonnet-5-5`. Без ключа и без сети всё работает: еда разбирается
по словам и через поиск, сводка недели собирается шаблоном.

## Что где

| Папка | Что |
| --- | --- |
| `js/core/` | ядро (аналог CoachCore): тренд, калибровка, правила раздела 5, защиты, сборщик стека, тренировки, база еды. Чистые функции, без DOM и хранилища |
| `js/data/` | хранилище IndexedDB (аналог Persistence): события с метками времени, мягкое удаление, экспорт JSON/CSV |
| `js/llm/` | единственный модуль LLM: системный промпт, лог запросов, валидатор сводки, фолбэк |
| `js/app/` | прикладной слой: связывает ядро и хранилище |
| `js/ui/` | экраны (дизайн временный) |
| `tests/` | тесты в браузере: 12-недельные сценарии, fuzz защит, пулы 10/20/40, лексикон |

## Отступления от ТЗ

- **Платформа:** PWA вместо Swift/SwiftUI — на этой машине нет Xcode. HealthKit недоступен: сон и шаги вводятся вручную.
- **Калибровка:** изменение веса для ΔTDEE считается регрессией по окну 28 дней, а не разностью EMA: EMA с α=0.1
  отстаёт на ~9 дней и занижала TDEE на 100–300 ккал первые недели. EMA остаётся для отображаемого тренда.
  Первые 2 недели — наблюдение: потом формульная оценка заменяется фактической, дальше k = 0.3/0.5.
- **«Истинный TDEE» при занижении лога на 20%** недостижим ни одной формулой по логу: модель сходится к расходу
  «в единицах лога». Поэтому бюджет всё равно даёт нужную фактическую скорость (тест замкнутого цикла).
- **Сборщик на пуле из 10:** 89–95% дней в допуске 10% (критерий ТЗ — 95%). Мешает правило «не больше 2 дней подряд»
  при пуле ровно из 10: без него 96%. На пулах 20 и 40 — 100%.
